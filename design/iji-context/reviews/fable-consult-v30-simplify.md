## 先に結論

1. **推奨の形**：候補を隠すのは「元の請求の行、または候補そのもの（施設基準・行の属性）が理由で、データの上で算定できないと決まるとき」だけにする。候補どうしの関係（包括・背反）と、手書きのルール（R ルール）の指摘は、**隠さずに添え書きで出す**。回を重ねる掛け直し・見直し・回の上限・「どちらかの組」・足す前と後の差は、全部なくす
2. **止まることと約束**：掛け直しは「候補の数＋2 回」で必ず終わる。約束は「作り方そのもの」になるので、繰り返しの途中の状態で破れることがない。codex の重い 2 件（X-151・X-152）は、どちらも繰り返しの中で起きるものなので、起きる場所がなくなる
3. **失うもの**：往診と同じ日の訪問診療料、週 3 回を超える訪問診療料、往診の翌日の訪問診療料などが、隠れずに「注意つき」で並ぶ。**影響が出るのは、取り込んだ請求（UKE）にカルテを貼った患者の、約 50 区分（訪問診療料・往診料・管理料など）の取り忘れだけ**。検査・処置・注射・投薬（全項目の側）の結果は、候補どうしの包括・背反が両方抜けた場合を除いて変わらない
4. **spec**：FR-194 の文は「包括・背反・回数と施設基準」だけを挙げていて、R ルールは挙げていない。今の設計のほうが spec より広く隠していた（L-96）。単純にすると spec の文の範囲に戻るので、**直しは必須ではない**。ただし解釈が 1 つ入る（候補どうしの包括・背反）ので、FR-194 に 1 文足すことを勧める
5. **round-53 の中くらいの指摘**：C-270 は消える。C-273 はほぼ消える（段の表の書き直しで確かめる）。C-272 は軽くなって残る。C-271・C-274 は施設の申告の側（§15-2）の話で、単純化と関係なく直す必要がある

## 1. 推奨の形

### 規則（4 つの手順。繰り返さない）

候補は今までどおり（足す行為、投薬の組、手技と薬の組、決まった規則で足す候補、量の差の単位）。組は 1 つの候補として扱う。

| 手順 | すること | 結果 |
|---|---|---|
| 1. 1 つずつ見る | 候補 c ごとに「元の請求＋c だけ」を作り、データの点検（G03〜G06・G10）で c に結び付く抑えを見る。相手は元の請求の行か、c そのもの（行の属性・施設基準の届出なし）だけ | 抑えがあれば**隠す**（「算定できない見込み」の一覧へ。理由つき）。これで決まりで、あとで戻さない |
| 2. まとめて 1 回 | 手順 1 を通った候補を全部足した請求を 1 つ作り、データの点検で**候補どうし**の関係を見る | 包括される側・背反で算定しない側の候補は**隠さず**、「『〔相手の名前〕』（これも取り忘れの候補）を算定すると、〔包括／背反〕で算定できません」を添える。背反区分 3（どちらか一方）の組は今までどおり 1 件 `G11.missing_either` にまとめる。回数（G06）の扱いも今のまま |
| 3. 手書きのルールを 1 回 | 同じ請求（元の請求＋手順 1 を通った候補の全部）に、担当のルールと R18 を 1 回掛ける | 候補 c が関わる指摘（指摘の区分に c の区分が入り、指摘が日を持つなら c の日がその中に入る）を、c の**添え書き**にする。隠さない |
| 4. 出す | 手順 1 を通った候補を全部出す。添え書きのある候補は「注意つき」として、添え書きのない候補の後ろにまとめる | 点検の範囲に「注意つきで出したもの：n 件（理由ごと）」を出す |

添え書きの文は、指摘の種類で 3 つだけ（どれも今の設計にある文を使う）：
- 区分誤りで、直し先が候補と同じ族 →「正しい区分は〔名称〕の恐れがあります（〔ルールの指摘の名前〕による）」（C-250 のまま）
- 情報不足 →「〔事実の名前〕を確かめないと算定できるかは言えません」（今のまま）
- ほか（要件不足・算定不可・背反・別の族の区分誤り）→「〔ルールの指摘の中身〕に当たる恐れがあります。算定できるか確かめてください」

「元の請求に出ています」「ほかの候補と一緒に足すと」「どちらかを算定しない恐れ」の言い分けはやめる（どの候補が原因かを決めようとしたことが、崩れた根だった）。

### 施設基準の扱い（FR-194 を守る所）

- 施設基準の届出なしで隠すのは、G10 の内部の入口（`blocking`。重なりの規則で消す前の結果）の「持たない」だけで行う。在宅医療DX情報活用加算の届出なしも、G10 の側では「持たない」なので、R12 に頼らずに隠せる見込み（未確認：`blocking` が、R12・R18 に譲る前の結果を返す作りかどうか。設計の文は「§12-2 の重なりの規則で消す前の生の結果を見る」）
- 例外は 1 つ：候補のコードが、施設の種別違いなどの「同じ族の区分誤り」に当たるとき（R18 が直し先を持つとき）は、G10 の「持たない」では隠さず、「正しい区分は〔名称〕の恐れ」を添えて出す（C-250 のまま。取り忘れそのものは確かなため）。今の設計でも、ここで G10 と C-250 のどちらが勝つかは文から読み取れなかった（未確認）。書き直すときに 1 行で決めておく
- 申告が分からない（`G10.unknown` だけ）は、今までどおり隠さず添え書き（C-232）

### 約束（テストで縛るもの。3 つ）

1. 出した候補はどれも、「元の請求＋その候補だけ」でデータの抑えが結び付かない
2. 隠した候補はどれも、「元の請求＋その候補だけ」でデータの抑えが結び付く（背反区分 3 で 1 件にまとめた組は「出した」に数える）
3. 出した候補を全部足した請求で、ある候補にデータの抑え（相手は別の候補）か、手書きのルールの指摘が関わるなら、その候補に必ず添え書きがある

3 つとも、ほかの候補を残すか外すかに依らない（1 と 2）か、1 回の評価をそのまま写すだけ（3）。途中の状態がないので、「止まったときに成り立つこと」を別に確かめる必要がない。結果が候補の並べ方に依らないことも、手順からそのまま出る。

### なくなるもの

- 「残す」「待ち」の集合、回、見直しの繰り返し、回の上限（L-124）、「繰り返しても決まらなかった」
- R ルールで候補を抑えること、足す前と後の差（鍵の数え合わせ。C-241）、1 つずつ／まとめての場合分け、「どちらかの組」（L-125 の中身）
- 添え書きの決め直し、「止まったときに成り立つこと」の 3 つの約束
- R18・担当のルールが判定できないときに候補を言わない決まり（添え書き「手書きのルールで判定できない行があります」に替える）

### 残るもの（変えない）

- データの点検が動かないとき、請求ごとに取り忘れを止める決まり（X-131）
- 抑えを足した単位に結び付ける決まり（X-137）、内部の入口 `blocking`（X-138）、回数の扱い（L-114）、背反区分 3 の 1 件（L-113）、取り違えの見込みで言わない組
- 言わなかった候補の一覧（L-96 の足し）、投薬の組、手技と薬の組、量の比較
- R ルールと 2 回言わない決まり（R03・R14 の取り忘れ、R01 を条件つきに下げる）
- R10・R13 の指摘が関わる日（`days`）。添え書きを関わる日の候補だけに付けるために残す（隠すためには使わない）

## 2. 依頼にあった候補（「まとめて足した 1 回」だけで見る）との違い

依頼の候補とほぼ同じだが、**隠す理由を「相手が元の請求の行か、候補そのもの」に限る**所だけが違う。

まとめて足した 1 回だけで「包括される側を隠す」と、次の 2 つが残る。
- 施設基準の届出なしで算定できない候補 A が、A に包括される候補 B を隠す（docs M-2 の穴が戻る）
- codex の X-151 の例（a と b がどちらか一方、a が c を包括）で、c が a に包括されて隠れる。a を算定するかは決まっていない

「隠した候補を前提に、別の候補を隠さない」を規則で守ろうとすると、また見直しが要る。そこで、候補どうしの関係では隠さないことにした。相手の候補はまだ請求にないので、「算定できないと決まる」とは言えない、という考え方。

### 足せる 1 段（勧めないが、選べる）

候補どうしでも、「相手が、データの上でどの候補にも負けていない候補」のときだけ隠す、という 1 段を足せる。K10 の例（在宅酸素の指導管理料と酸素吸入が両方抜けたとき、酸素吸入を隠す。X-140）は v29 と同じ結果になる。繰り返しは要らない。
ただし、規則が 1 つ増え、「相手が注意つきでも隠れる」場合の扱いを決める必要が出る。これまで、工夫を 1 つ足すたびに次の穴が出てきたので、**最初は足さない**ことを勧める。段 18c の報告で「候補どうしの添え書き」の数を数え、多ければ次の版で足す。

## 4. 失うもの・増えるもの

### 増えるもの（医療事務の目に入る候補）

- **注意つきの候補が出る場面は 2 種類**
  1. 取り込んだ請求にカルテを貼った患者で、訪問診療料・往診料・管理料などの約 50 区分が請求になく、手書きのルールが当たるとき。代表は、往診と同じ日の訪問診療（R10）、週 3 回を超える訪問診療（R13）、往診の翌日の訪問診療（在支診以外。R10）、訪問のない月の管理料（R01）、看取り加算と死亡診断加算の組（R09）
  2. 包括する側と包括される側（または背反の組）が、両方とも請求から抜けているとき
- **どれくらい増えるか**：数は未確認（測っていない）。言えるのは範囲だけ。算定プレビュー（合成の症例）の経路では 1 が起きない（約 50 区分は G11 が見ない）。検査・処置・注射・投薬は、相手が請求にある包括・背反なら今までどおり隠れる
- **実在の請求では、差はもっと小さい見込み**：round-53 の C-272 のとおり、実在の UKE では R10・R13 の事実（別表第七に当たるか、急性増悪か、など）が分からないのがふつうで、その場合は今の設計でも「情報不足の添え書きつきで出る」。隠れるのは事実が分かっているときだけだった（推測。実在の請求では数えていない）
- **一番気になる例**：同じ日に往診と訪問診療があり、医療事務が正しく往診料だけを請求している患者。カルテを貼るたびに「訪問診療料がありません（同じ日に往診料があります）」が注意つきで出る。毎月出る患者がいれば、わずらわしい

### 和らげ方（勧める）

- 注意つきの候補は、添え書きのない候補の後ろにまとめ、数を点検の範囲に出す
- 添え書きは、ルールの番号ではなく中身を先に書く（「同じ日に往診料があります」）。一目で「これは足さない」と分かるようにする
- 段 18c の報告で、注意つきで出た数を理由ごとに数える。多い理由があれば、その理由だけ次の版で隠す側に戻すかを決める

### 失うもの

- 「算定できないものは並ばない」という見た目のきれいさ。注意つきの中には、算定できない見込みのものが混じる
- 注意つきの候補を、注意を読まずに請求へ足す恐れ（点数が上がる向きの間違い）。指摘はいつも条件つきで、点数・金額は出さず、防いだ額にも数えない。この備えは変わらない

### 得るもの

- 確実に止まる。約束が作り方から直接出る。テストが「結果」だけで書ける（回の記録をのぞく入口が要らない）
- 手書きのルールで隠したときの**誤って隠す**間違いがなくなる。R10 は「原則」で、訪問診療のあとの急変の往診などの例外がある。隠すと医療事務は例外に気づけないが、注意つきなら自分で決められる
- 言わなかった候補の一覧（たたんだ一覧）を開かなくても、判断の材料が同じ場所に並ぶ

### 利用者の最優先に照らして

| 最優先 | 評価 |
|---|---|
| 実務に耐える | **良くなる**。今の形は、4 巡の批評でも止まり方と約束が固まらなかった。実在の請求で、理由の分からない出方をする恐れが一番大きい。単純にした形は、出方を 1 行で説明できる（「請求の行とぶつかるものは隠す。ほかは注意を添えて出す」） |
| 医療事務が楽になる | **少し下がる所がある**。注意つきの候補を読む手間が増える。ただし範囲は上のとおり狭く、隠れたものをたたんだ一覧で探す手間は減る |
| 全項目 | **広がる向き**。隠す範囲が狭くなり、言わない取り忘れが減る |

## 5. spec FR-194 との関係

- FR-194 の 2 段落目：「包括・背反・回数（G04〜G06）と施設基準（FR-189）で算定できないと決まるものは出さない」。**R ルールは挙がっていない**。今の設計は、R ルールや条件つきの指摘でも隠す側に倒していて、spec より広かった（設計の L-96 に、そう書いてある）
- 単純にした形は、R ルールで隠すのをやめるので、spec の文の範囲に戻る。前の相談で「FR-194 の 2 段落目に触れる」と書いたのは、読みが粗かった。文そのものとは食い違わない
- 施設基準は G10 の「持たない」で隠すので、「施設基準（FR-189）で算定できないと決まるものは出さない」も守る（1 の「施設基準の扱い」。未確認の所あり）
- **解釈が 1 つ入る**：包括・背反の相手が、請求の行ではなく別の候補のとき、「算定できないと決まる」に当たらないとして隠さない。ここは利用者に決めてもらう所
- 受け入れ条件 B（「包括されて算定できない行為では出ない」）は、症例の行為を 1 つずつ請求から外す形なので、相手は請求に残っていて隠れる。変わらない
- FR-56（取れない算定まで取りにいかせない）：注意つきで出すことは「促す」に寄るので、上の和らげ方（後ろにまとめる・中身を先に書く・条件つきのまま）を設計に書く

**勧め**：spec の直しは必須ではないが、あとで読む人が迷わないよう、FR-194 に 1 文足す。案：「相手が請求にない（どちらも取り忘れの候補である）包括・背反と、手書きのルールの指摘が関わる候補は、隠さずに、その旨を添えて出す。」（足すのは利用者の承認のあと、呼び出し側で）
