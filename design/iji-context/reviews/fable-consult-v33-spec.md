# Fable への相談：v33 の仕様（FR-205〜211）（2026-11-23）

相談した人：Opus。答えた人：Claude Fable 5.2（読むだけ）。要旨を呼び出し側がまとめた。

## 仕様に足りない 3 点（設計の前に足すのを勧める）
- (a) 調剤料・処方料・処方箋料は、今の G11 がすでに規則で出している（剤形・日ごとの院内・院外の本人の選択）。新しいのは麻薬等加算・患家診療時間加算・材料加算の 3 つで、ほかは入力元をオーダーに替えるだけ。オーダーと施設の申告・本人の選択が食い違うときの優先が未定義
- (b) 在医総管を算定する月は投薬の費用が包括（告示 C002 注3。EM 7-6・A34）で、調剤料などの候補はほぼ出ない。受け入れの症例を在医総管のない月とある月の両方に。実務の本命は在医総管の「処方箋を交付しない場合の加算」（R8-18）
- (c) 「空」が 3 つの意味（接続先が対応していない／0 件／n 件）。項目の欠けも別。能力の申告を型で持つ。全訪問の時刻を手で入れさせるのは「楽になる」に反するので、入力は必須にせず「見ていません」と数を出し、効く場面だけ入力を求める

## そのほか
- 重なり（FR-206）：AI は今までどおり取り出し、マスターに当てたあと日＋コードで突き合わせる。両方にあれば構造化を正（数も構造化）、文章にだけあれば「文章にあるがオーダーにない」の条件つき候補（口頭指示・オーダーの入れ忘れ。実務で一番値打ちがある）、当てられないものは本人が同じかを選ぶ。今の FR-209・図8 の「構造化で来た行為は除く」はこれと食い違い、文章にだけある行為が落ちる
- 機器（FR-208）：正は患者の情報。電子カルテの指示は「変える案」として届き本人が確かめる。終わりの月がない。材料加算は機器だけで決まらない（指導管理料を算定する機関か・入院・回数の決まり）。指導管理料そのものを見るか未定。K9・K10 の症例の作り直しが要る
- 患家診療時間加算：電子カルテの時刻がカルテを開いた時刻の恐れ（推測。問い合わせに足す）。条件つきで出し、境の手前では言わない
- コードの体系（YJ・独自）と対応表、麻薬等加算の区分を医薬品マスターから読めるか、構造化データを AI に送らない、FR-210 の「全件」の表、FR-211 の同じ略語のまとめ方
- 95%（FR-209）：「この評価の組で」と限る。分母を ID で先に固定。直しに使う組と合否だけの組を分け、線は後者に。150〜200 行為以上に増やす目安。余計な取り出しの数と上位 5 件を並べる。古い 80% の結果は消さずに並べる。正解の作り直しが要る
- FR-207 のほかに規則で出せるもの（EM に値がある）：処方箋を交付しない場合の加算（R8-18）、在宅療養指導管理料そのもの（R8-22 など。R04）、酸素濃縮装置加算（R8-23）、ベースアップ評価料・物価対応料の日ごとの行（R08・R15）、訪問診療料の同一建物の取り違え（L-164。R8-1・R8-2）、特定疾患処方管理加算・一般名処方加算（在医総管のない月）。EM に値がなく今は入れないもの：往診の夜間・休日・深夜の加算ほか
