## 100 点に届くための直しの順

1. 医師への問いを答えられる形にする（#1）：患者を特定する番号（カルテ番号か院内の患者番号）を出す。別表第八の二の状態の一覧（要旨）を問いに添える。アップロードした請求では、レセプトの傷病名と在宅療養指導管理料などの行を「カルテの代わりの手がかり」として出す（点数・金額は伏せる）。
2. UKE の画面のメンターに、その画面の判定（摘要欄の R17 を含む）を渡すか、渡せない指摘を聞かれたときは「この指摘は私には見えていません。画面の根拠を見てください」と答えるようにする（#2）。
3. 全件の一覧を締めに使える数にする（#3・#4・#5）：UKE から取れない P06 は一覧の数に入れないか、患者ごとに 1 回答えれば次の月も消えるようにし、点検の画面から直接入れられるようにする。見本の保険者番号を検証番号の合う番号に直す。一覧の上に「残り n 件（確定・情報不足・患者情報のどれかが残る件数）」を出す。
4. 古い言い方を直す（#9〜#12）：取り込みの説明と docs/checks.md の「情報不足」を「見ていません」に、4 段階の表に「入れられないもの（カルテ側の記録）」を足す、患者情報の段階の読み方を README に書く。
5. 月末の動線の仕上げ（#6〜#8）：月末は UKE の画面から始まるよう入口かメニューの順を変える、「次のレセプトへ」を付ける、課長が部下の進み具合を見られるようにする。
6. 手間の残り（#13〜#16）：略語の印の拾い方、要介護度が分かっている患者の認定の問い、R17 の項番、「点検していないこと」の畳み方。
