## 100 点に届くための直しの順

1. 条件つきを「前提を確かめた」で閉じられるようにする（#1）：条件つき 1 件ごとに「前提を確かめた（当たらない／当たるので直す）」を本人が残し、残した分は残りから外す。残した人と日を一覧に出す。デモのクリニックでも使えるようにする。
2. 患者情報の指摘を点検の画面で入れられるようにする（#2）：P06・P03 の行に、資格の有効期限・負担割合の入力（`/coverages` と同じ部品）を置く。少なくとも患者情報の欄へのリンクを付ける。
3. 見本の保険者番号を検証番号の合う番号に直す（#3）。
4. 文言をそろえる（#8〜#12）：取り込みの説明の「情報不足」を「見ていません」に、4 段階の表に「入れられないもの（カルテ側の記録）」を足し、README の「指摘の読み方」に「残り」の数え方と患者情報の段階の読み方を書く。G12 の確定の文から前提を外すか、前提の置き方を README に書く。
5. 月末の動線の仕上げ（#5〜#7）：入口かメニューの順を月末の点検に寄せる、「次のレセプトへ」、課長が部下の進み具合を見られる一覧。
6. 手間と根拠の残り（#4・#13〜#15）：医師のカードに管理料の行を添える、要介護度が分かっている患者に認定を聞かない、略語の印、R17 の項番とリンク。
