## 0. 結論（先に）

| 問い | 答え | 根拠 |
|---|---|---|
| 形式は公式に分かるか | 分かる。増減点連絡書・返戻内訳書・再審査等支払調整額通知票などの CSV は資料1 に項目表がある。返戻レセプトそのもの（UKE 形式の CSV）は資料4 に記録条件仕様がある | 資料1 p.13–15、資料4 p.13, 37 |
| 返戻内訳書に UKE 形式のレセプトは入るか | 入らない。返戻内訳書は一覧の CSV。UKE 形式の返戻レセプトは別のファイル（`RECEIPTC.HEN`／`RECEIPTC.SAH`）で配られる | 資料1 p.49–54、資料2 p.315、資料4 p.13, 37 |
| 増減点連絡書に診療行為コードは入るか | 入らない。請求内容と査定後の内容は全角の文字列（最大1100文字）。コードで突き合わせるには文字列の解釈が要る | 資料1 p.48 |
| 事由記号 A〜K の公式の出典 | 資料1 別表6「事由コード」（p.148）と 資料6 別表1「事由コード」（p.48）。内容は同じ | 下の §5 |
| 復活を識別できるか | UKE 形式の再審査等返戻ファイル（SAH）なら、審査結果コード「111 復活」と事由レコードの補正区分「5 復活」で識別できる。返戻されない再審査結果（再審査等支払調整額通知票 CSV）には「復活」の項目はなく、増減点数の符号（＋）と請求理由で見分けることになる（推測） | 資料6 p.27, 31, 48–49、資料1 p.99–101 |

## 4. 返戻レセプト（UKE 形式）`RECEIPTC.HEN`／`RECEIPTC.SAH`

出典：資料4（別添Ａ）。

### 4-1. 共通

| 項目 | 内容 | 出典 |
|---|---|---|
| 記録形式 | CSV。可変長、項目はコンマ区切り、引用符は使わない | 資料4 p.13, 26 |
| 文字の符号 | シフト JIS（JIS X 0201 の8単位符号と JIS X 0208 附属書1） | 資料4 p.26 |
| 改行・終端 | CR LF でレコード区切り。最後に EOF（0x1A）1バイト | 資料4 p.13, 26 |
| ファイル名 | 一次請求返戻＝`RECEIPTC.HEN`、再審査等返戻＝`RECEIPTC.SAH` | 資料4 p.13, 37 |
| 構成 | 先頭 HI（返戻医療機関）→ 返戻レセプト（1件以上）→ 最後 HG（返戻合計） | 資料4 p.13, 37 |
| 返戻レセプトの中身 | 請求データ（RE〜SJ。一次請求の記録条件どおり。審査支払機関の補正後の内容）＋返戻理由（HR）＋履歴管理ブロック | 資料4 p.14–17 |
| 履歴管理ブロックの見分け方 | 行の先頭1文字が数字なら履歴管理ブロック。先頭に「データ識別, 行番号, 枝番号」が付く | 資料4 p.13 |

データ識別のコード（資料4 p.13）：1 請求、2 支払決定（審査支払機関の補正等）、3 再審査等（保険者等からの請求）、4 再審査等決定（再審査等の結果）、5 資格確認前請求、6 資格確認補正、8 返戻、11〜16 再請求前の各データ、85・86 返戻データ（資格確認前請求／資格確認補正）。
