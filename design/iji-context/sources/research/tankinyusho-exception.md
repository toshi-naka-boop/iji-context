# 「医療型短期入所中の者を除く」の例外は誰のためのものか

調べた日：2026-11-22。対象：留意事項通知（令和8年度 保医発0305第6号 別添1）の、在宅療養指導管理料を算定している患者の処置・検査の除外にある「医療型短期入所サービス費又は医療型特定短期入所サービス費を算定している短期入所中の者を除く」（EM §2-12 HX-21）。

## 結論

**受け入れた施設のため**。改定の説明資料にそう書いてある（根拠 1・2）。
ただし、通知の文は**患者の状態**（短期入所中か）で例外を決めており、**誰が処置したかは限っていない**。在宅の医療機関が、他の施設で短期入所中の患者に処置して算定できるかを明文で否定した資料は見つからなかった。この点は「決まらない」のまま残る（ただ、趣旨からは算定しない方へ読める。**推測**）。

### 病床のない在支診のレセプトで「当たらない」と言える条件

次の 2 つがどちらも成り立てば、「この例外に当たらない」と言ってよい。

1. **当院が医療型短期入所・医療型特定短期入所の指定事業所でない。** 医療型特定短期入所（宿泊を伴わない日中のみの受入れ）は**無床診療所も行える**（根拠 5）。病床がないことだけでは「受け入れた施設ではない」と決まらない。当院が指定を受けていれば、当院自身が受け入れた施設になり、例外に当たる。
2. **処置した日、患者が他の施設の医療型短期入所を利用していなかった**（自宅・居住系施設での処置）。

1 が成り立ち、2 が成り立たない（他の施設に短期入所中の患者に、当院の医師が処置した）場合は、文の上では例外から外れず、趣旨の上では受け入れた施設のための例外なので、判定は「決まらない」。tokurei-group3.md §1-3 の問い合わせ（関東信越厚生局 東京事務所）は残す。なお、在支診の医師が病院・老健などに短期入所中の患者のところへ往診して処置をする場面がそもそも算定上ありうるかは、ここでは確かめていない（**推測**：少ない）。

レセメンでの扱いの案（**推測**。判断は設計に委ねる）：施設の設定に「医療型（特定）短期入所の指定の有無」を持ち、指定なしなら問いの選択肢を「医療型短期入所中ではなかった（当たらない）」「他の施設で医療型短期入所中だった（決まらない）」「その他」「判定不能」に絞る。

## 根拠

### 1. 個別改定項目（平成28年度。H28 で足された除外）

- 「平成28年度診療報酬改定における主要改定項目」第1部（個別改定項目） https://www.mhlw.go.jp/file/06-Seisakujouhou-12400000-Hokenkyoku/0000114740.pdf PDF p249-250（印字 p248-249）。同じ文は https://www.mhlw.go.jp/file/05-Shingikai-12404000-Hokenkyoku-Iryouka/0000112306.pdf PDF p248 にもある
- 項目名：「医療型短期入所サービス中の処置等の評価」（骨子 Ⅲ－５(2)）
- 要旨：
  - 基本的な考え方：医療型短期入所での**重症児の受入れを促進**するため、入所中の医療処置等の診療報酬上の取扱いを明確にする。
  - 具体的な内容：在宅療養指導管理料を算定しているために入院外等では別に算定できない処置等を、医療型短期入所の利用中に算定できることを「明確化」する。対象は 18 項目（経皮的動脈血酸素飽和度測定、終夜経皮的動脈血酸素飽和度測定、中心静脈注射、植込型カテーテルによる中心静脈注射、鼻マスク式補助換気法、体外式陰圧人工呼吸器治療、人工呼吸、膀胱洗浄、後部尿道洗浄、留置カテーテル設置、導尿、介達牽引、矯正固定、変形機械矯正術、消炎鎮痛等処置、腰部又は胸部固定帯固定、低出力レーザー照射、鼻腔栄養）。
- 読み：目的が「受入れの促進」なので、算定するのは受け入れる側（事業所）と読める。除外の文は「管理料を算定している患者」で決まり、処置した医療機関を問わないので、他の医療機関である受け入れ施設も処置を算定できなかった。それを外すための例外、という筋になる（この因果の説明は**推測**。資料は「明確化」とだけ書く）。

### 2. 改定説明会資料（平成28年3月4日）

- 「平成28年度診療報酬改定説明（医科）」 https://www.mhlw.go.jp/file/06-Seisakujouhou-12400000-Hokenkyoku/0000115977.pdf PDF p109（スライド 109「小児医療・周産期医療・救急医療の充実①」）
- 要旨：個別改定項目と同じ文。重症小児の在宅移行の項目と並べて置かれている。処置等の例として中心静脈注射・鼻マスク式補助換気法・人工呼吸・留置カテーテル設置・導尿を挙げる。

### 3. 疑義解釈（平成28年 その4 問26）

- 疑義解釈資料の送付について（その4）、平成28年6月14日 事務連絡 https://www.mhlw.go.jp/file/06-Seisakujouhou-12400000-Hokenkyoku/0000142190.pdf PDF p10（印字「医科-9」の前のページ。見出し【処置の休日・時間外・深夜加算】）
- 要旨：医療型短期入所サービス費等を算定する短期入所中の者に、処置の通則5 ロ（入院中の患者以外に行った場合の休日・時間外・深夜加算）を算定できるかを問い、答えは「算定不可」。
- 読み：「短期入所中の者に行った処置」を算定する医療機関がある前提の問で、短期入所中の処置を入院外の扱い（時間外等の加算）にしない、という答え。受け入れた施設が処置を算定する場面を想定した問と読める（**推測**。問も答えも、誰が算定するかは書いていない）。前の調べ（tokurei-group3.md §1-3）の推測は、本文で確かめても推測のまま。
- 平成28年度の疑義解釈 その1〜その3・その5〜その8（0000119348・0000122794・0000124651・0000129200・0000135459・0000136971・0000143210）にも「短期入所」の語を検索したが、ほかの問はなかった。

### 4. 令和8年度までの変化

- 令和8年度の留意事項通知（§2-1 の「留意」 https://www.mhlw.go.jp/content/12400000/001757385.pdf ）に、同じ括弧書きが D223 (2)・D223-2 (2)（p415）、G005 (3)（p485）、G006 (3)（p487）、J026-2・J026-3（p561）、J045（p576）、J060・J060-2（p581）、J063・J064（p581-582）、J118・J118-2・J118-3（p585）、J119・J119-2・J119-3（p586）、J120（p587-588）にある。H28 の 18 項目と同じ範囲で、文言も同じ型（D223・D223-2 だけ「入院中の患者」の語がない）。
- 手元にある疑義解釈（令和2〜令和8年度の約 240 本。作業用フォルダに取得済みのもの）を「短期入所」で検索したが、医療型短期入所について問うものはなかった（介護老人保健施設の短期入所療養介護の問はある。令和2年3月31日 その1 問59）。平成30年度分は主な回しか見ていない。
- 扱いが変わったことを示す資料は見つからなかった。

### 5. 障害福祉サービス側（医療型短期入所）

- 実施できる施設：病院、診療所、介護老人保健施設、介護医療院。**宿泊を伴わない場合は無床診療所も実施できる**（医療型特定短期入所）。障害福祉サービス等報酬改定検討チーム 第37回（令和5年9月27日）資料1 https://www.mhlw.go.jp/content/12401000/001150500.pdf PDF p2・p21
- 報酬の性格：医療型短期入所サービス費は「1日当たりの支援に必要な費用」を包括的に評価する、とする留意事項（障発第1031001号の令和6年度改正の新旧対照。宮城県の転載 https://www.pref.miyagi.jp/documents/51616/05tankinyusyo.pdf PDF p6、印字 p157）。転載なので二次資料。厚労省の原本では確かめていない。
- **医療型短期入所の事業所が算定できる医療保険の範囲を決めた告示・通知は見つからなかった。** 「特別養護老人ホーム等における療養の給付の取扱いについて」（令和8年3月27日 保医発0327第5号による改正 https://www.mhlw.go.jp/content/12400000/001681750.pdf ）は、短期入所生活介護と指定障害者支援施設などを扱い、医療型短期入所には触れていない。福祉型の短期入所の医療連携体制加算について「医薬品等が医療保険の対象なら診療報酬を請求する」とする文はある（同じ宮城県の転載 印字 p164）が、医療型の話ではない。
