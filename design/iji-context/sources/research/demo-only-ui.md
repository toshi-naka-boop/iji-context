# 同梱の合成データでしか動かない箇所（画面・scripts・deploy・README/docs）

調べた日：2026-11-22。対象：`.claude/worktrees/integration`（feat/integration、83d1442 時点）の `app/`（`app/api/` を除く）、`scripts/`、`proxy.ts`・`next.config.ts`、`deploy/`、README.md・docs/。
コードを読んで判断した（サーバーは起動していない）。推測は「推測」と書く。src・app/api は別の担当の範囲で、ここでは画面に効くものだけを「範囲外」と添えて挙げる。

前提として確かめたこと：

- 取り込んだ UKE の請求 id は `U<連番>-<通し番号>`（`src/uke/upload.ts:8`）。同梱の症例は `K1-2026-10` の形。
- 取り込んだ請求は `cases()` に入る（`src/server/app/cases.ts:95`）。カルテ側の事実は全部「不明」、出来事なし、`recordsKnown: false`。対象外の単位があれば `partial: true` で、その単位は `lines` に入らない（`src/uke/cases.ts:97-101`）。
- エンジンは、記録のない請求では記録を読む指摘を捨てて情報不足（chartRecord）を 1 件返し、partial の請求では決められない指摘を捨てて情報不足（unsupportedLines）を返す（`src/engine/types.ts:203-208`）。
- `isCorrect` は「指摘が全部 情報不足なら正解」（`src/practice/practice.ts:52`）。
- 時計は `setting("now") ?? config/demo.json の clockStart`（`src/server/app/clock.ts:14-16`）。進めるのは `POST /api/clock` だけで、本番では 404（`src/server/policy.ts:141`・`171`）。
