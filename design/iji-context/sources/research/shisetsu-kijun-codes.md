# 施設基準コード（医科診療行為マスター 項番72〜81）の読み方と、届出との対応

調査日：2026-11-22。対象：令和8年度版のマスターファイル仕様説明書と、取り込み済みの医科診療行為マスター（snapshot 20261102）。

## 結論（先に）

1. **10 個の欄は 3 つのグループに分かれ、グループの中は OR、グループの間は AND。** ①〜⑥＝グループ①、⑦〜⑨＝グループ②、⑩＝グループ③。全部 0 のグループは条件に入れない。
2. **名称の出どころは仕様説明書の別紙7-8「施設基準コード関連情報」（R08rec2.pdf の p120〜173）。** 機械で読める形（CSV など）の公式の一覧は見つからなかった（診療報酬情報提供サービスのダウンロードにあるのは、訪問看護療養費マスターの「施設基準テーブル」だけ）。
3. 在宅の主な行の対応表は §3。在医総管・施設総管は「在支診の種別（グループ①の OR）」かつ「在医総管の届出 721（グループ②）」。
4. **厚生局の名簿の「受理番号」は（略称）第N号の形で、略称と施設基準の名称の一覧が各局から PDF で出ている。マスターの施設基準コードとの公式の対応表は見つからなかった。** 名称の照合で対応はおおむね取れる（§4 の表。照合は推測）。クリニックが略称で届出を選び、それをコードに引く形は作れる。
5. 注意：コードは「届出」のほかに「施設の種別（在支診か）」「名寄せ（どれか 1 つ）」「基準を満たさないときの減算の行に付く基準」も表す（§5）。**取り込み済み DB の `shisetsu` 列は欄の位置を捨てているので、このままでは AND と OR を区別できない**（§5-1）。

## 1. 複数のコードが入っているときの意味

出典：レセプト電算処理システム マスターファイル仕様説明書 令和8年度版
- 本文 R08rec1.pdf https://shinryohoshu.mhlw.go.jp/shinryohoshu/file/spec/R08rec1.pdf p41（印刷ページ。PDF の 45 枚目）：項番72〜81「施設基準①～⑩」は「先頭から最大１０項目まで施設基準コードを設定する」。コードは「別紙７－８」による。
- 別紙 R08rec2.pdf https://shinryohoshu.mhlw.go.jp/shinryohoshu/file/spec/R08rec2.pdf 別紙7-8「３ 施設基準コードの設定要領」p172〜173（PDF の 82〜83 枚目）。

要旨：
- グループ①＝施設基準①〜⑥、グループ②＝⑦〜⑨、グループ③＝⑩。
- グループ内：「いずれかの施設基準を満たしている場合に算定できる」（p172）＝OR。
- グループ間：「グループ間の施設基準を、いずれも満たしている場合に算定できる」（p172）＝AND。
- 各グループの値がすべて 0 なら、そのグループは条件に入れない。全部 0 なら施設基準を要しない行。
- 設定例①（p172）：①236・②237 → 画像診断管理加算1 か 2 のどちらかの届出。設定例②（p173）：①3236・②3238・⑦3300 → (3236 か 3238) かつ 3300。

式で書くと：算定できる ⇔ 値のあるグループのそれぞれで、少なくとも 1 つのコードを満たす。

取り込み済みマスターでの件数（原本 CSV `raw/shinryo/20261102/s_20261102.csv` を直接数えた）：施設基準のある行 4,623、うち 2 つ以上のコードがある行 1,297、2 つ以上のグループにまたがる（AND がある）行 901。

## 2. 施設基準コードの名称の出どころ

- **別紙7-8「１ 施設基準コード一覧」**（R08rec2.pdf p120〜160。PDF の 30〜70 枚目）。医科のあと【医療観察診療報酬点数表によるもの】【歯科点数表によるもの】が続く。テキスト抽出で約 1,940 件を確認。
- **別紙7-8「２ 名寄せコード一覧」**（p161〜171）：名寄せコード（8001〜）は「原則として７つ以上の施設基準要件があり、そのうち、何れかの要件を満たしている場合」に使う代表コード（p161 の要旨）。在宅で効くのは 8032「在宅療養支援診療所（名寄せコード）」＝3055・4247・3056・3168 のどれか（p172 上段。C001 注12 に基づく）。
- 一覧の名称は欄の幅で切れているものがある。例：721 は一覧では「在宅時医学総合管理料及び施設入居時等医学」で切れている（p122）。厚生局の略称一覧では「在宅時医学総合管理料及び施設入居時等医学総合管理料」。
- 機械で読める形：診療報酬情報提供サービスの基本マスターのダウンロード https://shinryohoshu.mhlw.go.jp/shinryohoshu/downloadMenu/ に、医科の施設基準コード一覧のファイルはない（2026-11-22 に確認）。あるのは訪問看護療養費マスターの「施設基準テーブル」（別紙10-5 のコード。医科とは別体系）。**医科の一覧は PDF からの抽出しかない**（ほかの公開元は未確認）。
- 調剤（別紙9-4）・訪問看護（別紙10-5）は別のコード体系（R08rec1.pdf 目次）。医科のコードと混ぜない。

### 4-2. マスターのコードとの対応
- **厚生局の略称・受理番号と、マスターの施設基準コードを結ぶ公式の表は見つからなかった（未確認。仕様説明書・厚生局のページ・略称一覧のどれにもない）。**
- 名称の照合では §3-1 のとおりおおむね 1 対 1 に取れる。ずれる所：
  - ベースアップ評価料（Ⅱ）は略称が「（外在ベⅡ１～24）」の 1 つで、マスターは区分ごとに別のコード。区分の番号は受理番号の略称からは分からない（名簿の備考に出るかは未確認）。
  - 在支診・在支病は病院用のコード（3057 など）と診療所用が別。届出の略称も別なので照合できる。
  - 名寄せコード 8032 は届出の名称には出ない。名寄せ元（3055・4247・3056・3168）のどれかを届け出ていれば満たすと読む。
- クリニックが自分の届出を選ぶ形：**作れる（推測）**。略称一覧の「略称＋施設基準の名称」を選択肢にし、裏で施設基準コードを持てばよい。対応の表は手で作ることになる（§2 のとおり公式の機械で読める表がないため）。名簿の Excel から医療機関番号で引けば初期値にできる見込み（ZIP の中身は開いていない。未確認）。
- 届出には算定開始年月日がある。診療年月と比べるなら、届出ごとに開始日を持つ必要がある（名簿の列からの推測）。

## 5. 注意点

### 5-1. 取り込み済み DB の `shisetsu` 列
- `src/masters/build.ts` 62 行目で、10 個の欄から 0 を除いてカンマでつないでいる。**欄の位置（どのグループか）が残らない。** 例：114031610 の `3055,4247,721` は本当は「(3055 か 4247) かつ 721」。全部 AND と読むと在支診（１）と（２）のアを両方要求してしまい、全部 OR と読むと 721 がなくても通ってしまう。
- 突き合わせに使うなら、グループごとに持つ形で読み直す必要がある（コードは変えていない。設計の判断は別途）。

### 5-2. コードが「届出」以外を表す場合
- **施設の種別**：3055・4247・3056・3168 などは「在支診であること」。在支診の届出があることと同じだが、行ごとに「機能強化型か」「病床があるか」で別のコードの組が付く。床の有無はマスターの施設基準ではなく行の分け方で表している。
- **名寄せ**：8032 のように「どれか 1 つ」を表す代表コードがある（§2）。届出の選択肢には出さず、名寄せ元に展開して判定する。
- **基準を満たさないときの行**：在宅患者訪問診療料の「基準不適合・５回目以降」の行には在支診のコード（8032 など）が付く。「基準を満たさない」こと自体はマスターに表れない。
- **注14 の減算の行**：単一建物 10 人以上の（減算）行に 4101（在医総管 注14）が付く。告示 C002 注14 は「別に厚生労働大臣が定める基準を満たさない場合には、それぞれ所定点数の100分の60」（令和8年厚生労働省告示第69号 別表第一 https://www.mhlw.go.jp/content/12400000/001686842.pdf PDF の 144 枚目）。**基準を満たさないときに使う行に、その基準のコードが付いている。「届出があれば算定できる」とは読めない行がある。** 4101 を届出の有無とどう突き合わせるかは、特掲告示・特掲通知の注14 の基準と、届出の様式を読んで決める（未確認）。
- **逓減の別の項目**：項番44「適合区分」・45「対象施設基準」は、基準を満たさないとき逓減した点数を算定する行を表す（R08rec1.pdf p35）。施設基準①〜⑩とは別の列。今のマスターで値があるのは 13 行（高エネルギー放射線治療など）で、在宅の行にはない。
- **マスターにない届出**：看取り加算・往診料・訪問診療料の基本の行など、施設基準の欄が 0 でも、患者の状態など別の要件がある。施設基準の欄が 0 なら届出の点検の対象外、というだけ。
- コードは版ごとに足される（例：救命救急入院料１(令和８年６月１日以降) 4868 のように版の名前が付いたコードがある。p157）。版ごとにマスターと一覧を持ち替える。
