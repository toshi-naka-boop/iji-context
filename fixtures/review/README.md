# 合成の増減点連絡書・返戻内訳書（査定・返戻の突き合わせ。spec FR-202 の I-1）

ここにある CSV は**合成**です。実在の患者・医療機関・審査の結果ではありません。氏名・番号・医療機関コード（9999999）は架空です。

**書式は推測です**。項目の並び・ファイル名の規則・レコード種別・前の行の値を引き継ぐ省略規則は、公開の資料の項目表（`design/iji-context/sources/research/zogen-henrei-format.md` §1〜§3）に合わせましたが、実物の CSV は見ていません。次の点は推測で作っています：文字コード（下の表）、引用符を使わないこと、ヘッダの項目の並び（項番 2 を診療月）、項番 5・17 などの資料に要旨のない欄を空にしたこと、「請求内容」「補正・査定後内容」の文字列の書き方、箇所1 に診療識別の 2 桁を入れたこと、返戻の事由コード（`1234`）。
