# R02

在宅酸素療法中など別表第八の二に当たる患者に、月 2 回以上訪問診療を行った月は、重症区分（2イ）で算定する。重症区分で算定する月に包括的支援加算は付けない

根拠：C002 2イ・C002-2 2イ（別に厚生労働大臣が定める状態＝別表第八の二）・C002 注10

判定はルールエンジン（R02）が行う。この知識は判定の理由を説明するときに引用する。
