# R15

外来・在宅物価対応料は、訪問診療料を算定した日は訪問診療時の区分、往診料だけの日は再診時等の区分を使う。訪問診療料と往診料の両方を算定した日に再診時等を重ねられるかは、施設で確かめた設定による

根拠：O100 外来・在宅物価対応料（留意事項 (3)(4)）

判定はルールエンジン（R15）が行う。この知識は判定の理由を説明するときに引用する。
