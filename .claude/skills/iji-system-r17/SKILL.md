# R17

摘要欄には、記載要領の別表Ⅰ で項目ごとに定められた記載を、その項目のコメントコードで書く。管理料（在宅時医学総合管理料・施設入居時等医学総合管理料）はその月に往診又は訪問診療を行った年月日、包括的支援加算は当たる状態、在宅移行早期加算は初回の管理料を算定した年月日、在宅ターミナルケア加算は死亡年月日（在宅以外で亡くなったときは、死亡前 24 時間以内の訪問診療の年月日と時刻も）、在宅酸素療法指導管理料はその月の動脈血酸素分圧又は動脈血酸素飽和度。訪問診療料と同じ日に往診料を算定したときは往診が必要になった理由、急性増悪で週の限度を超えて訪問診療を行ったときは必要性・必要を認めた日・訪問した日を書く

根拠：診療報酬請求書等の記載要領 別表Ⅰ（摘要欄への記載事項）

判定はルールエンジン（R17）が行う。この知識は判定の理由を説明するときに引用する。
