# R03

包括的支援加算は、管理料の区分が 2ロ・2ニ の月に、別表第八の三の状態（要介護3 以上、認知症の日常生活自立度Ⅲ以上、週 1 回以上の訪問看護、訪問診療・訪問看護での処置、麻薬の投薬など）の患者に付ける。要介護3 未満でも、ほかの状態に当たれば対象。施設入居時等医学総合管理料でも同じ

根拠：C002 注10 包括的支援加算（C002-2 注5 で施設入居時等医学総合管理料に準用）

判定はルールエンジン（R03）が行う。この知識は判定の理由を説明するときに引用する。
