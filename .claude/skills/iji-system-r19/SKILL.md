# R19

管理料（在宅時医学総合管理料・施設入居時等医学総合管理料）は、単一建物診療患者の人数（その月に、その患者が住む建物で在宅時医学総合管理料か施設入居時等医学総合管理料を算定する人の数）の区分（1 人、2〜9 人、10〜19 人、20〜49 人、50 人以上）で算定する。同じ建物で 2 人以上を診ている建物がないと施設が申告していれば、どの患者も 1 人の区分。摘要欄の戸数によるみなしの記載がある在宅時医学総合管理料は 1 人の区分で算定できる

根拠：C002 注1・C002-2 注1（単一建物診療患者の人数による区分）・留意事項 C002 (3)・(11)

判定はルールエンジン（R19）が行う。この知識は判定の理由を説明するときに引用する。
